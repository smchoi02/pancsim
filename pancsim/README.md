# pancsim — 신규 당뇨 췌장암 조기 발견 패치의 기대 효과 시뮬레이션

50세 이상 신규 당뇨 환자 가상 코호트를 대상으로 한 개인 단위 몬테카를로 미시 시뮬레이션입니다.
CGM(연속혈당측정)과 A-mode 초음파(복부 피하지방 두께)를 합친 패치를 **설명서대로 쓸 때**와 **쓰지 않을 때(현재 진료)**를
같은 가상 환자에게 적용해, 사용자 1만 명당·전국 연간 기대 효과를 계산합니다.

- 설계와 근거: 「시뮬레이션 설계서」
- 파일·함수별 설명: 「시뮬레이션 코드 설명서」
- 결과 해석: 「기대효과 분석 정리」

## 1. 무엇을 비교하나

| 코드 | 비교 대상 | 내용 |
|---|---|---|
| `S0` | 쓰지 않을 때 (현재 진료) | 선별 없음. 증상이 생겨야 진단 |
| `S9g` | 패치를 쓸 때 | 당뇨 진단 후 0·3·6·12·18·24·30·36개월에 2주씩 착용(3년 8회). 착용마다 학습된 모형이 위험 확률을 계산하고, 기준선을 넘으면 CT → 필요 시 내시경초음파 조직검사. 정밀검사에서 암이 아니면 12개월간 재검하지 않음 |
| `S1` | ENDPAC → CT (검증용) | 모델이 ENDPAC 성능을 재현하는지 확인하는 검증 표에만 씀. 비교 전략 아님 |

기본 분석은 **설명서대로 사용**(모든 회차 착용, 중단 없음, 양성이면 모두 정밀검사)을 가정합니다. 실제 사용(착용 80%, 연 27% 중단, 검사 수용 90%)은 시나리오로 봅니다.

## 2. 설치

```bash
pip install -r requirements.txt
```
Python 3.11 이상. 한글 그래프에는 한글 글꼴(Windows 맑은 고딕, macOS 애플고딕, Linux Noto Sans CJK 등)이 필요합니다.

## 3. 실행 (저장소 최상위에서)

```bash
python run_impact.py                 # 1) 본 분석 → results_impact/기대효과.xlsx (약 15~30분, --fast 는 약 3분)
python presentation/sched.py         # 2) 착용 일정 × 재검 제한 비교 → presentation/sched.csv (약 5분)
python presentation/figs.py          # 3) 그래프 17장 → presentation/figures/
python presentation/tables.py        # 4) 표 → presentation/발표용_결과표.xlsx
```

자연경과 보정을 다시 하려면 `python calibrate.py 400000` (약 7분, `calibrated_nh.json`이 바뀜). 보통은 필요 없습니다.

저장소에 들어 있는 결과 파일(`results_impact/기대효과.xlsx`, `presentation/` 아래 결과)은 위 순서로 만든 사본입니다. 같은 코드와 시드로 다시 돌리면 같은 값이 나옵니다.

## 4. 파일 구성

| 파일 | 설계서 | 하는 일 |
|---|---|---|
| `params.py` | 3~8장 | 모든 입력값. 줄마다 [참고문헌 번호]와 근거 등급(A~D). 값 바꾸기는 여기서 |
| `natural_history.py` | 3.3절 | 암 진행(P0 → 국한 → 국소 진행 → 원격 전이)과 증상 진단의 경쟁 위험(연속시간 마르코프) |
| `calibrate.py` | 3.4절 | 근사 베이지안 계산(ABC)으로 진행 속도와 A형 등록 시 단계를 보정 → `calibrated_nh.json` (기본 1개 + 채택 107개). 이전 보정은 `calibrated_nh_old.json`(시나리오용) |
| `lifetable.py` | 3.1절 | 2024 생명표에 맞춘 곰페르츠 배경 사망 × 당뇨 환자의 나이별 사망 배수 |
| `cohort.py` | 3~4장 | 가상 환자(대조군 / A형: 등록 때 이미 암 / B형: 등록 후 3년 안에 새로 생긴 암)와 몸의 실제 값(혈당, 복부 피하지방, 체중) |
| `strategies.py` | 5~7장 | 패치 측정(오차 포함), 판정 모형(그래디언트 부스팅, 특징 12개), 정밀검사(CT → 내시경초음파 조직검사), 재검 제한 규칙, ENDPAC |
| `outcomes.py` | 8장 | 진단 병기별 생존(같은 단계 조기 발견 이득 포함), 삶의 질(QALY), 비용, 할인 |
| `simulate.py` | 8장 | 학습 코호트로 판정 모형을 만들고 시험 코호트에서 평가. 대조군·A형·B형을 유병률로 가중 |
| `validate.py` | 9장 | 패치 없이 돌린 결과를 실제 통계(진단 시점·병기·생존·ENDPAC 성능)와 비교 |
| `psa.py` | 11.6절 | 확률 민감도 분석의 입력값 분포(`SPEC`)와 한 세트 뽑기(`draw`) |
| `impact.py` | 11장 | **본 분석**: 1만 명당 효과, 전국 환산, 성능 지표, 병기 이동별 이득, CT 판독 수준 비교·놓친 횟수, 완벽한 기기 대비 실현 비율, 시나리오, 상관 민감도, 확률 민감도 분석 |
| `run_impact.py` | — | 본 분석 전체 실행 → `results_impact/` |
| `presentation/` | — | 결과 엑셀로 그래프·표를 만드는 코드 (3장 실행 2~4) |

## 5. 결과 엑셀 (`results_impact/기대효과.xlsx`)

| 시트 | 내용 |
|---|---|
| 1만명당_효과 | 쓰지 않을 때 / 패치를 쓸 때 / 차이: 진단 수, 증상 전 발견, 병기별 진단, 생존연수, QALY, 비용, CT, 내시경초음파, 암이 확인되지 않은 정밀검사, 착용 횟수 |
| 전국_연간 | 전국 연 15만 명(10만~25만 명) 환산 |
| 완벽한기기_대비 | 완벽한 기기 대비 실현 비율 |
| 성능지표 | 기기 민감도(종양이 있을 때 양성)·특이도·양성예측도, 전체 경로 민감도(CT·조직검사까지), CT 1건당 암 확인 |
| 병기이동별_이득 | 원래 단계 → 발견 단계별 인원, 1명당 생존 증가, 평균 앞당김 |
| CT_판독수준, CT_놓침_단계별 | 판독 수준(현재·PANDA·CT 100%·확진 100%)별 결과, 정밀검사 시점 단계별 놓친 횟수 |
| 검증 | 모델 vs 실제 자료 |
| 시나리오, 상관_민감도 | 가정을 하나씩 바꾼 결과 (시나리오용 작은 표본) |
| PSA_요약, PSA_원자료 | 확률 민감도 분석 60회 |

## 6. 값을 바꿔 돌리기

```python
import params, impact
p = params.get(fat_loss_total=0.22, ct_cooldown_m=0)       # 입력값 덮어쓰기
t = impact.impact_table(p)                                   # 1만 명당 효과
```
시나리오 목록은 `impact.SCENARIOS`, 상관 설정은 `impact.CORR_GRID`, CT 판독 수준은 `impact.CT_LEVELS`에서 고칩니다.

## 7. 재현성

- 사람마다 난수를 미리 정해 두고(공통 난수), 쓰지 않을 때와 쓸 때가 같은 난수를 씁니다. 두 결과의 차이는 패치 때문입니다.
- 판정 모형은 조기 종료를 끄고 난수 시드를 고정해, 같은 입력이면 같은 결과가 나옵니다.
- 시나리오(대조군 5만 명)와 본 분석(20만 명)은 표본 크기가 달라 기본값이 조금 다릅니다.

## 9. 한계

입력값의 근거 등급과 한계는 설계서 9장·13장에 정리했습니다. 특히 같은 단계 조기 발견 이득의 반영 비율(50%), 기기 가격, 전국 신규 당뇨 수는 가정값이며, 판정 모형은 가상 자료로 학습했으므로 실제 성능은 낮을 수 있습니다.
